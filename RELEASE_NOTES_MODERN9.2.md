# OpenCobolIDE 4.7.6+modern9.2

This maintenance update adds a short troubleshooting page to the offline Help.

If the menu bar disappears or the main window opens with a broken layout, the
new page explains how to back up the OpenCobolIDE configuration, start with a
clean layout, and restore the previous settings if needed.

The procedure affects IDE preferences only. COBOL source files and project
data are not removed.

## Install

```sh
sudo apt install ./opencobolide_4.7.6+modern9.2_all.deb
```
