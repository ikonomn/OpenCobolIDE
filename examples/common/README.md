# GnuCOBOL / COBOL Debugger Examples

Open **Help → About COBOL Debugger → Examples** to find the writable examples.
Open an example's README and build it from its own folder.

| Example | What to try |
| --- | --- |
| [Hello](hello/README.md) | Set your first breakpoint and watch a variable change |
| [Easter](easter/README.md) | Enter a year and inspect a report calculation |
| [Countries](countries/README.md) | Read records from a data file |
| [Graphical score](gui/README.md) | Click a button in an X11 window and step through COBOL |
| [EU Cities](eu-cities/README.md) | Step through a GixSQL cursor over SQLite |

Keep the executable and the generated C and header files from the same debug
build. Rebuild after moving an example to a new folder.

See [data sources](DATA-SOURCES.md) for the Countries and EU Cities datasets.
